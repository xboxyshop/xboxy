# Regole per le pagine XBOXY

## Favicon browser obbligatoria
Ogni nuova pagina HTML, landing page, homepage e pagina legale del sito XBOXY deve includere nel `<head>` questo riferimento:

```html
<link rel="icon" type="image/png" href="https://xboxy.shop/favicon.png?v=20261018" sizes="64x64">
```

Usare il file `/favicon.png` nella root della repository come favicon condivisa. Non sostituire, ridisegnare o omettere il logo nelle pagine future. La stessa favicon assoluta funziona anche nelle pagine sotto percorsi e sottodomini come `go.xboxy.shop`.
